  ---------------
  \| CubeCar \|
  ---------------

CubeCar is a compact, portable car-in-a-box. CubeCar is designed to
allow university students to get where they're going quickly, without
needing to deal with the hassle of walking. CubeCar comes in a
lightweight carrying case, assembling itself in less than 10 seconds.
Its hover wheels let it pass over obstacles and snow without issue.
Never be late for class again!
